I added a new tab today. `ideas` has been doing double duty for a while now &mdash; part changelog, part running commentary, part place to think out loud in public. That works fine for short entries, but it's the wrong shape for anything that needs more room to breathe.

So: `blog` is for the longer stuff. Essays, retrospectives, the occasional story. Things that have a beginning, a middle, and an end, instead of a timestamp and a paragraph.

## What goes where

The split I'm going to try to hold myself to:

- **Ideas** stays a log. Short, dated, tagged, filterable. If it's a note about something I'm using or building this week, it goes there.
- **Blog** is for posts that stand on their own. Longer, less time-bound, meant to be read start to finish rather than skimmed in a list.

I don't expect that line to be perfectly clean in practice, but it's a useful default when I'm deciding where to put something.

## Why now

No particular reason beyond wanting a place for writing that doesn't fit the log format. The site was already set up to make this cheap &mdash; a new collection, a layout, a listing page &mdash; so there wasn't much reason to keep putting it off.
